# Contributing

This is a solely owned personal project by Chris Clark. It is published under
the MIT license so others can read and reuse the code, but it is not run as a
community project.

- I am the sole owner and maintainer. There is no contributor agreement, and I
  do not accept assignments of copyright.
- Outside pull requests are generally not merged. If you spot a bug or a
  security issue, open an issue describing it instead.
- No real club, team, coach, player, or family data belongs in this repository.
  All sample data and test fixtures are synthetic and must stay that way.
